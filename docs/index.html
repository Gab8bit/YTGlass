Features

Everything yt-dlp can do. Nothing you have to type.

A focused, native front end — every flag and format yt-dlp supports, wrapped in something you'd actually enjoy using.

📥

Priority queue

Reorder, pause, retry or remove downloads — yours stays exactly the order you want.

🎚️

Quality picker

From 480p to full 4K, or drop straight to the smallest available file.

🎵

MP3 extraction

Grab audio only, converted with ffmpeg at the highest quality.

🖼️

Live thumbnails

See what you're downloading, with real-time progress and transfer speed.

📋

Clipboard detection

Copy a link, and YTGlass offers to queue it — no need to switch apps.

📃

Playlists & subtitles

Queue an entire channel in one go, with subtitles downloaded alongside.

🔔

System notifications

Get notified the moment a download finishes or fails — no need to babysit it.

🌐

Italian & English

Follows your system language automatically, or pick one yourself in Settings.

How it works

From link to file in three steps

1

Install yt-dlp

YTGlass drives the real yt-dlp CLI under the hood, installed via Homebrew.

2

Paste a link

Drop in any URL yt-dlp supports — pick quality, audio-only, subtitles or playlist mode.

3

Watch it land

Track progress live, get notified on completion, and jump straight to the file in Finder.

Requirements

macOS 26 Tahoe · Homebrew · two minutes

YTGlass is free, open source, and runs entirely on your Mac — no accounts, no tracking, no cloud.

# First, either way: the tools YTGlass drives
brew install yt-dlp ffmpeg
⬇️

Option A — Download the app

Download the latest release, unzip it and move YTGlass.app to Applications. Since it isn't notarized with a paid Apple Developer ID, the first launch needs one extra step: right-click (Control-click) the app → Open → Open in the dialog that appears. Only needed once.

🛠️

Option B — Build it yourself

No Gatekeeper prompt this way, and you can read every line first.

git clone https://github.com/Gab8bit/YTGlass.git
cd YTGlass && ./build_app.sh
